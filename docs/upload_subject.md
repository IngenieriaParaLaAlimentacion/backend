Épica
Talla, Peso y Georreferenciación

Descripción
Como Responsable de Comedor, profesional autorizado o administrador, quiero registrar sujetos (niños/as relevados) para poder asociarles mediciones antropométricas y realizar seguimiento nutricional dentro del sistema.

Criterios de aceptación
CA 1: Registro de identidad del sujeto


El formulario debe permitir ingresar un identificador único (DNI o ID equivalente), sexo, fecha de nacimiento, nombre, apellido, pertenencia a población rural y pertenencia a población indígena.

No puede cargarse un sujeto sin todos los campos obligatorios.
CA 2 — Validación de unicidad


El sistema no debe permitir registrar dos sujetos con el mismo identificador.
CA 3 — Persistencia del sujeto


Una vez confirmado el formulario, el sujeto debe almacenarse en la base de datos y quedar disponible para futuras mediciones.
CA 4 — Asociación futura


El sujeto registrado debe poder vincularse posteriormente con mediciones antropométricas y comedores.
